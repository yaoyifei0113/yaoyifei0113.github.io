很明显，这是一个异或操作，提取出encrypted_array中的数据，写一段脚本和0xAD异或，脚本如下：

data = [0xDE, 0xED, 0xDA, 0xF2, 0xDD, 0xD8, 0xD7, 0xD7, 0x00]
key = 0xAD

results = []
for byte in data:
result = byte ^ key
results.append(result)

print("原始数据（十六进制）:", [hex(b) for b in data])
print("异或密钥（十六进制）:", hex(key))
print("异或结果（十六进制）:", [hex(r) for r in results])
print("异或结果（十进制）:", results)

ascii_chars = []
for r in results:
if 32 <= r <= 126: # 可打印ASCII字符范围
ascii_chars.append(chr(r))
else:
ascii_chars.append('?') # 非打印字符用?表示

print("ASCII字符表示:", ''.join(ascii_chars))

XOR

查壳，打开，分析

![](C:\Users\39172\Pictures\Screenshots\屏幕截图 2026-04-16 205206.png)

分析可知，对str先判断长度，由结果可知是24，再判断i除以3的余数，进而对其进行异或操作，接着初始化v 5的值，再进行第二次异或操作，逆着进行解密，脚本如下：

目标字符串

target_str = "anu_ym7wKL1$P]v3q%D]lHpi"

初始化v5数组

v5 = [19, 19, 81]

正确的解密流程：先逆向第二次异或，再逆向第一次异或

flag = ""

for i in range(len(target_str)):

第一步：逆向第二次异或（与v5数组异或）

​ char_after_first_xor = ord(target_str[i]) ^ v5[i % 3]
``

第二步：逆向第一次异或（根据索引位置选择不同的密钥）

​ if i % 3 == 0:
​ original_char = char_after_first_xor ^ 0x14
​ elif i % 3 == 1:
​ original_char = char_after_first_xor ^ 0x11
​ else: # i % 3 == 2
​ original_char = char_after_first_xor ^ 0x45
​
​ flag += chr(original_char)

print(f"解密后的flag: {flag}")
print(f"flag长度: {len(flag)}")

最后得到flag 解密后的flag: flaX{y0u_K30W_b4s1C_xOr}
